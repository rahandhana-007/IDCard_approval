Hubungkan ke Supabase

ID Card Management memakai database online (Supabase): akun, kunci tanda tangan, antrean pengajuan, dan riwayat tersinkron antar perangkat — user bisa mengajukan dari mana pun, manager menyetujui dari perangkat lain.

Buka di browser/perangkat lain tanpa mengisi ulang: pakai link berparameter ?sb_url=…&sb_key=…, atau gunakan build dengan koneksi tertanam (lihat README — Membawa koneksi ikut file). Configurasi & sesi tersimpan per-browser (localStorage), jadi masing-masing browser tetap perlu login sekali.

Langkah menyiapkan Supabase (gratis):
1. Buat proyek di supabase.com.
2. Buka SQL Editor → jalankan seluruh isi file supabase/schema.sql.
3. Authentication → Providers → Email → matikan Confirm email.
4. Settings → API → salin Project URL dan anon public key ke form ini.
Akun pertama yang dibuat di aplikasi otomatis menjadi manager.

5 Catatan keamanan

Aplikasi berjalan di browser dengan backend Supabase (Auth + Postgres + Row Level Security). Yang dikirim ke server: akun/login, gambar & data kartu pada antrean pengajuan, payload QR hasil, dan blob kunci privat yang sudah terenkripsi AES-256-GCM dengan frasa sandi Anda — server tidak pernah melihat kunci privat dalam bentuk terbuka. Proses kriptografi (pembuatan kunci, hash, tanda tangan, QR) tetap 100% di browser. Untuk produksi skala besar, pertimbangkan HSM / layanan tanda tangan terpusat.

Integritas
SHA-256 atas (metadata + byte gambar) ditandatangani. Perubahan apa pun membatalkan validitas.
Autentikasi
Hanya pemegang kunci privat yang bisa menerbitkan tanda tangan sah.
Non-repudiasi
Tanda tangan asimetris (ECDSA/RSA) dapat diverifikasi siapa pun dengan kunci publik.
Replay
Payload memuat kid + ts + hash gambar; tambahkan cek daftar hitam/revokasi di sistem Anda bila perlu.
